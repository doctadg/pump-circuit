# Free asset sources

All third-party assets in this directory are frozen locally so the game does not depend on runtime asset hosts.

## Kenney 3D models — CC0 1.0

- Racing Kit: https://kenney.nl/assets/racing-kit
- Toy Car Kit: https://kenney.nl/assets/toy-car-kit
- Nature Kit: https://kenney.nl/assets/nature-kit
- Space Kit: https://kenney.nl/assets/space-kit
- License: https://creativecommons.org/publicdomain/zero/1.0/

Selected `.glb` files were copied unchanged from the packs and renamed by category for a smaller production payload. Kenney attribution is not required under CC0, but the source is recorded here for provenance.

## Poly Haven PBR textures — CC0

- Asphalt 02: https://polyhaven.com/a/asphalt_02
- Leafy Grass: https://polyhaven.com/a/leafy_grass
- Coast Sand 03: https://polyhaven.com/a/coast_sand_03
- Moon 02: https://polyhaven.com/a/moon_02
- License: https://polyhaven.com/license

The 1K JPG diffuse, OpenGL normal, and roughness maps were downloaded from Poly Haven, checksum-verified against its API metadata, resized to 768px, and converted to WebP for browser delivery. No visual content was regenerated.
